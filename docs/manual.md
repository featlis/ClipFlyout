# ClipFlyout マニュアル

README に入りきらない詳細をここにまとめています。対象バージョンは v2.2.0 です。

## インストール

### インストーラー版（推奨）

1. [GitHub Releases](https://github.com/featlis/ClipFlyout/releases/latest) から `ClipFlyout-Setup-v2.2.0.exe` をダウンロードします
2. インストーラーを実行します（標準ユーザー権限でインストールできます）
3. インストール後に表示される初回セットアップ画面で、既定設定の適用か、言語・基本動作の初期選択を行います

### ポータブル版（ZIP）

1. `ClipFlyout-v2.2.0-win-x64.zip` をダウンロードし、任意のフォルダーに解凍します
2. フォルダー内の `ClipFlyout.exe` を起動します（設定はローカル AppData に保存されます）

ダウンロードの検証用に、各リリースには SHA-256 チェックサム一覧（`checksums-sha256.txt`）が付いています。

## 基本操作

1. 起動すると、システムトレイ（通知領域）にアイコンが表示されます。左クリックで直前のフライアウトの再表示、ダブルクリックで設定画面が開きます
2. 任意のアプリケーションでテキストや画像をコピー（`Ctrl + C`）します
3. 画面端に表示されるフライアウトのボタンをクリックすると、変換や整形が実行されます。変換系のアクションを実行すると、次のフライアウトにはペーストボタンが提示されます。キーボードでは `Esc` で閉じ、`↑` / `↓` + `Enter` や数字キー `1`〜`9` でアクションを選べます
4. フライアウトが消えたあとでも、リコールショートカット（既定は `Alt + Shift + C`、設定で変更可能）で直前のフライアウトを再表示できます
5. タスクバー上のウィジェットをクリックすると直前のフライアウトが表示されます。右クリックで位置切り替えや非表示のメニューが開きます。全画面アプリの使用中は自動で隠れます
6. フライアウトの中では、コピー内容をその場で編集（クイック編集）したり、前のクリップと結合したりもできます

### トレイから使えるもの

- **履歴**: 最近のコピーが並びます。ピン留めしたものは履歴クリアの対象から外れます。履歴の保存（永続化）は既定でオフで、設定でオンにできます
- **定型文**: よく使う文を保存しておき、トレイから直接挿入できます。設定画面で追加・編集します
- **一時停止**: 監視を 15 分 / 1 時間だけ止められます。再開もトレイからできます
- **テーマと言語**: トレイからも切り替えられます

## 対応データ型とアクション一覧

| データ型 | 検出条件 | 提供される主なアクション |
| :--- | :--- | :--- |
| **カラーコード** | `#RGB`, `#RRGGBB`, `rgb()`, `hsl()` | カラープレビュー、HEX / RGB / HSL / RGBA 変換コピー |
| **Unix タイムスタンプ** | 10 桁（秒）または 13 桁（ミリ秒）の数値 | ローカル日時文字列変換、ISO 8601 変換、現在 Epoch コピー |
| **ISO 8601 日時** | `YYYY-MM-DDTHH:mm:ssZ` 等 | ローカル日時、Unix 秒 / ミリ秒変換コピー |
| **ファイル / フォルダ** | エクスプローラーでコピーしたファイル・フォルダ | フルパス / 引用符付きパス / ファイル名コピー、エクスプローラーで開く |
| **JSON テキスト** | JSON オブジェクト `{...}` または配列 `[...]` | インデント整形コピー、1 行化（Minify）コピー |
| **Web URL** | `http://` または `https://` リンク | 既定ブラウザで開く、QR コード画像生成コピー、ホストドメインコピー |
| **クリーン URL** | UTM トラッカーや追跡パラメータを含むリンク | 追跡パラメータを除去したクリーン URL のコピー |
| **メールアドレス** | メールアドレス形式の文字列 | 既定メールアプリ起動、ドメインコピー、ユーザー名コピー |
| **Base64 / Data URI** | Base64 文字列、Data URI | プレーンテキスト復号、画像データ展開・クリップボード転送 |
| **表データ (CSV / TSV)** | カンマまたはタブ区切りの表形式テキスト | Markdown テーブル形式への変換、JSON 配列への変換 |
| **コードスニペット** | プログラミング言語構文・インデント構造 | インデント正規化（スペース 2 文字）、HTML 特殊文字エスケープ |
| **識別子ケース変換** | camelCase, snake_case, PascalCase, kebab-case | キャメルケース・スネークケース・ケバブケース相互変換 |
| **JWT トークン** | 署名付き JWT 文字列 | クレームペイロード（JSON）のデコード展開 |
| **ファイルパス** | Windows / POSIX `/` / UNC / `/mnt/...` (WSL) パス | スラッシュ変換、WSL ⇔ Windows 変換、エスケープ、ターミナルを開く |
| **数式 / 進数変換** | 四則演算、`0x...` (16進)、`0b...` (2進) | 10 進数 / `0xHEX` / `0bBIN` 変換コピー（日付・電話番号・バージョン等は誤検出除外） |
| **UUID / GUID** | ハイフン付き UUID / `{GUID}` | 小文字 / 大文字 / ハイフン除去コピー、UUID v4 / v7 新規生成 |
| **クリップボード画像** | クリップボード内のビットマップ画像 | 解像度・アスペクト比の確認、PNG / JPG / BMP 保存、オンデバイス OCR 文字起こし |
| **プレーンテキスト** | 上記に該当しない通常のテキスト | 前後空白トリム、文字数カウント、大文字 / 小文字、SHA-256、Base64 エンコード、前のクリップと結合 |

## 設定項目

トレイアイコンを右クリックし、「設定」を選択すると設定画面（Mica デザイン）が開きます。

### 全般

- クリップボード監視の有効 / 無効
- タスクバーウィジェットの表示 / 非表示、表示位置（トレイ左、中央右、中央左、左端、タスクバー直上）、左右位置の微調整、対象モニター選択、文字色（自動 / 明色 / 暗色）
- パスワードマネージャー除外の有効 / 無効と、プロセス名単位の除外リスト（自分でアプリを追加できます）
- リコールショートカットの有効 / 無効とキーの変更
- Windows ログオン時の自動起動
- テーマ切り替え（システム準拠 / ライト / ダーク）
- 表示言語（自動 / 日本語 / English）
- 履歴の保存（永続化）の有効 / 無効
- 定型文の管理

### フライアウト外観 & 動作

- 表示位置（右下 / 右上 / 左上 / 左下 / カーソル付近）
- アクリル透明度（20% 〜 100%）
- アクセントカラー選択（システムのアクセントカラー、プリセット、RGB カスタム指定。テーマに合わせた自動調整もあります）
- 表示継続時間（1.5 秒 〜 10 秒）
- カーソル離脱後の待機時間（0.5 秒 〜 5 秒）
- 全画面アプリ使用中の表示抑制

### 検出フィルター

- データ型の検出や補助機能（クリーン URL、ケース変換、JWT、OCR など）ごとに、個別の有効 / 無効を設定できます

### アップデート

- 設定画面内またはトレイから、GitHub Releases の最新バージョン確認と更新インストールができます
- 更新ファイルはこのプロジェクトの GitHub Releases からのみ取得し、実行前にリリースの SHA-256 一覧で検証します

## プライバシーに関する詳細

- 解析と変換はすべてローカルで処理され、クリップボードの内容が外部サーバーへ送信されることはありません。画像 OCR も Windows 標準の OCR を使うオンデバイス処理です
- 履歴の永続化は既定でオフです
- パスワードマネージャーの除外判定は、コピー元ウィンドウのプロセス名で行います。対象は 1Password、Bitwarden、KeePass、KeePassXC、LastPass、Dashlane、Enpass、NordPass、RoboForm、Proton Pass です
- アプリ側がクリップボードに付けた除外指定も尊重します（`Clipboard Viewer Ignore`、`CanIncludeInClipboardHistory` が 0 のもの、`ExcludeClipboardContentFromMonitorProcessing`）

## トラブルシューティング

### フライアウトが表示されない

トレイメニューで「クリップボード連携」が有効になっているか、一時停止になっていないか確認してください。また、パスワードマネージャーからのコピーは仕様として自動的に除外されます。全画面アプリの使用中は、設定により表示が抑制されます。

### タスクバーウィジェットの位置を調整したい

ウィジェットを右クリックするか、設定画面の「タスクバーウィジェット」項目から配置プリセットと「左右微調整」を使用してください。

### すりガラス効果（アクリル）が適用されない

Windows の「設定」>「アクセシビリティ」または「個人用設定」>「色」で「透明効果」が有効になっていることを確認してください。省電力モード時やリモートデスクトップ接続時は、Windows 側の制約によりアクリル効果が無効化される場合があります。
